# QUẢN LÝ KHÁCH HÀNG

## Mô tả

Chương trình quản lý danh sách khách hàng bằng C++.

## Chức năng

* Nhập danh sách n khách hàng.
* Hiển thị danh sách khách hàng vừa nhập.
* Sắp xếp khách hàng theo tổng tiền thanh toán tăng dần bằng Insertion Sort.
* Tìm kiếm khách hàng có tổng tiền thanh toán bằng X bằng Binary Search.

## Thông tin khách hàng

Mỗi khách hàng gồm:

* Mã khách hàng
* Tên khách hàng
* Số điện thoại
* Tổng tiền thanh toán
